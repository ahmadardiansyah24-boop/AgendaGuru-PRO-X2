# AgendaGuru PRO X 2.0

Aplikasi administrasi guru berbasis HTML/CSS/JavaScript yang siap di-hosting melalui GitHub Pages.

## Struktur

- `index.html` — halaman utama
- `css/style.css` — stylesheet
- `js/app.js` — logika aplikasi
- `assets/` — aset tambahan

## Fitur

- Login & Setup Admin
- Sekolah & Guru
- Kelas & Siswa
- Jadwal
- Jurnal Mengajar
- Absensi
- Nilai
- Kokurikuler
- Denah Tempat Duduk
- Administrasi & Cetak
- Manajemen Akun
- Backup & Restore

## Menjalankan di GitHub Pages

1. Buat repository baru di GitHub, misalnya `AgendaGuru-PRO-X2`.
2. Upload seluruh isi folder ini.
3. Pastikan `index.html` berada di root repository.
4. Buka **Settings → Pages**.
5. Pilih **Deploy from a branch**.
6. Pilih branch `main` dan folder `/ (root)`.
7. Simpan dan buka URL GitHub Pages yang diberikan GitHub.

> Data aplikasi versi ini disimpan di `localStorage` browser. Jadi data tidak otomatis tersinkron antar perangkat/browser.
