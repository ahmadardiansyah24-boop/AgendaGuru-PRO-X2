# Rumah PPM & LKPD AI

AI Studio starter for a teacher document generator using Gemini.

## Import to Google AI Studio
Use Build > Add files (+) > Import from GitHub. The app is designed to run as a full-stack Node.js project.

## Environment
Set GEMINI_API_KEY as a server-side Secret/Environment Variable.
Optional:
- GEMINI_TEXT_MODEL (default gemini-3.8-flash)
- GEMINI_IMAGE_MODEL (default gemini-3.1-flash-image)

## Product vision
1. Ikuti Template Saya
2. Desain oleh AI
3. PPM / Modul / LKPD / Asesmen / Rubrik
4. Template Intelligence
5. Gemini Image Studio
6. Quality Validator
7. CP -> TP -> ATP -> PPM -> LKPD -> Asesmen -> Rubrik

Never put API keys in client-side code.
